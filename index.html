Поддерживаемые протоколы

Работа с прокси

Veyron поддерживает два типа прокси-подключений.

HTTP
SUPPORTED

HTTP Proxy

Подключение через HTTP-прокси с поддержкой HTTPS CONNECT-туннелей.

S5
SUPPORTED

SOCKS5

Поддержка SOCKS5 для работы с совместимыми сетевыми приложениями.

Краткая информация о проекте Veyron.

Veyron — приложение для управления сетевыми подключениями, прокси-профилями и параметрами соединения.
В текущей версии поддерживаются HTTP Proxy и SOCKS5.
Нет. Текущая версия предназначена для работы с прокси-подключениями и не является полноценным системным VPN-клиентом.
Исходный код проекта доступен в публичном репозитории Veyron на GitHub.
