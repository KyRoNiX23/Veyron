# Veyron

**Veyron** — настольное приложение на C# для управления сетевыми подключениями, прокси-серверами и маршрутизацией трафика.

Проект разрабатывается на .NET 10 с использованием Windows Forms.

## Возможности

- Импорт прокси из CSV и URI.
- Поддержка HTTP и SOCKS5.
- Проверка доступности прокси-серверов.
- Управление профилями подключений.
- Локальный HTTP-прокси.
- Маршрутизация трафика по доменным правилам.
- Разделение подключений на Proxy, Direct и Block.
- Запуск Google Chrome и Microsoft Edge через локальный прокси.
- Мониторинг активных подключений.
- Подсчёт отправленного и полученного трафика.
- Сохранение пользовательских настроек.

## Маршрутизация трафика

Veyron поддерживает три режима маршрутизации:

| Режим | Описание |
|---|---|
| GlobalProxy | Весь поддерживаемый трафик через прокси |
| RuleBased | Маршрутизация по доменным правилам |
| GlobalDirect | Прямые подключения |

Доступные действия:

- **Proxy** — подключение через выбранный прокси.
- **Direct** — прямое подключение.
- **Block** — блокировка подключения.

### Пример: маршрутизация YouTube

Для настройки маршрутизации YouTube можно использовать следующие правила:

| Домен | Действие |
|---|---|
| `youtube.com` | Proxy |
| `*.youtube.com` | Proxy |
| `youtu.be` | Proxy |
| `googlevideo.com` | Proxy |
| `*.googlevideo.com` | Proxy |
| `ytimg.com` | Proxy |
| `*.ytimg.com` | Proxy |
| `youtubei.googleapis.com` | Proxy |
| `youtube.googleapis.com` | Proxy |
| `youtube-nocookie.com` | Proxy |
| `*.youtube-nocookie.com` | Proxy |

Остальные домены можно направлять напрямую с помощью `DefaultAction = Direct`.

## Локальный прокси

Локальный прокси используется как промежуточный сервер между браузером и выбранным внешним прокси.

Стандартный адрес:

```text
127.0.0.1:2080
```

Схема подключения:

```text
Browser
   |
   v
127.0.0.1:2080
   |
   v
TrafficRouter
   |
   +---- Proxy ----> Upstream Proxy
   |
   +---- Direct ---> Destination
   |
   +---- Block
```

## Поддерживаемые протоколы

| Протокол | Статус |
|---|---|
| HTTP Proxy | Поддерживается |
| SOCKS5 | Поддерживается без авторизации |
| SOCKS4 | Частичная поддержка в отдельных компонентах |
| HTTPS Proxy | Требует дальнейшей реализации |
| WireGuard | Зависит от реализации соответствующего провайдера |
| OpenVPN | Требует реализации |

**Примечание:** текущий `LocalProxyServer` поддерживает HTTP CONNECT и не является полноценным системным VPN. Он не перехватывает весь системный трафик Windows.

## Установка и запуск

### Требования

- Windows 10 или Windows 11.
- .NET 10 SDK.
- Visual Studio 2022 или новее.
- Доступ к сети для проверки внешних прокси.

### Сборка

Открой терминал в корневой папке проекта:

```powershell
dotnet restore
dotnet build
```

Запуск:

```powershell
dotnet run --project src/Veyron.Client
```

Если проект использует другое расположение `.csproj`, укажи фактический путь.

## Хранение данных

Пользовательские данные рекомендуется хранить в:

## Ограничения текущей версии

- Локальный прокси пока не поддерживает обычные HTTP GET/POST-запросы.
- SOCKS5-аутентификация не реализована.
- HTTPS-прокси требует отдельной реализации TLS-соединения с прокси-сервером.
- Не реализован полноценный системный VPN-туннель.
- Не все сетевые компоненты поддерживают параллельное завершение соединений.
- Правила маршрутизации применяются к доменам из HTTP CONNECT.

## Безопасность

- Локальный прокси по умолчанию привязывается к `127.0.0.1`.
- Не рекомендуется открывать локальный прокси для внешних сетевых интерфейсов без дополнительной защиты.
- Не следует хранить пароли прокси в открытом виде.
- Используйте только прокси-серверы, доступ к которым у вас разрешён.
